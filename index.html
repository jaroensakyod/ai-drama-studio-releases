📱 ดาวน์โหลดแอป Android

กำลังดูเวอร์ชันล่าสุด ...

วิธีติดตั้ง (ทีละขั้น)

  1. ปิด Play Protect ชั่วคราวก่อนถ้าไม่ปิด Google จะบล็อกการติดตั้ง ("แอปถูกบล็อกเพื่อปกป้องอุปกรณ์ของคุณ") เพราะแอปขอสิทธิ์ Accessibility
    เปิดแอป Play Store → กดรูปโปรไฟล์มุมขวาบน → Play Protect → กด ⚙️ มุมขวาบน → ปิด "สแกนแอปด้วย Play Protect" → กดปิด (ไม่ต้องรอ ปิดแล้วติดตั้งได้ทันที)
  2. กดปุ่ม "ดาวน์โหลดแอป Android" ด้านบนChrome จะเตือน "ไฟล์อาจเป็นอันตราย" → กด "ดาวน์โหลดต่อไป" (เป็นคำเตือนปกติของไฟล์ .apk ทุกไฟล์) → รอจนขึ้น "ดาวน์โหลดเสร็จสมบูรณ์" → กด "เปิด"
    ถ้าแถบหายไปก่อน: Chrome → ⋮ มุมขวาบน → ดาวน์โหลด → กดไฟล์ AI-Drama-Studio
  3. อนุญาตให้ Chrome ติดตั้งแอป (ครั้งแรกครั้งเดียว)ขึ้นว่า "โทรศัพท์ของคุณไม่ได้รับอนุญาตให้ติดตั้งแอปที่ไม่รู้จักจากแหล่งที่มานี้" → กด "การตั้งค่า" → เปิดสวิตช์ "อนุญาตจากแหล่งที่มานี้" → กดย้อนกลับ → กดไฟล์ในหน้าดาวน์โหลดอีกครั้ง
  4. กด "ติดตั้ง"มือถือบางยี่ห้อ (เช่น TECNO, Infinix, Xiaomi) จะขึ้นหน้าตรวจความปลอดภัยของตัวเอง เช่น "อาจมีความเสี่ยง" → รอปุ่มนับถอยหลังจบ แล้วกด "เพิกเฉย" / "ติดตั้งต่อ" → ขึ้น "ติดตั้งแอปแล้ว" → กด "เปิด"
  5. เปิด Play Protect กลับติดตั้งเสร็จแล้ว กลับไปเปิดสวิตช์ในขั้นที่ 1 ได้เลย แอปยังใช้งานได้ปกติ
  6. ขอ licenseหน้าแรกของแอปแสดง รหัสเครื่อง → กดปุ่ม 💬 "ขอ / ต่ออายุ license" (รหัสเครื่องถูกคัดลอกให้อัตโนมัติ) → วางส่งในแชท → ได้รหัส license กลับมา → วางในแอป → ติ๊ก "ฉันยอมรับ" → เปิดใช้งาน
  7. อ่านและยอมรับข้อตกลงขึ้นครั้งเดียวต่อเวอร์ชัน
  8. ทำตามหน้า "🔧 ตั้งค่าเครื่องครั้งแรก" ในแอป ทีละข้อทุกข้อมีปุ่มพาไปหน้าตั้งค่านั้นเลย:
    • ติดตั้งแอป Meta AI จาก Play Store → เปิดแล้วล็อกอินด้วยบัญชี Facebook สำรอง → กลับมาติ๊ก "ล็อกอินแล้ว"
    • แอป Meta AI เป็นภาษาไทย → ถ้าขึ้น ❌ กด "ตั้งภาษา" → เพิ่มภาษาไทยไว้บนสุด
    • สิทธิ์เข้าถึงไฟล์ → เปิดสวิตช์ → ย้อนกลับ
    • สิทธิ์ Accessibility → หาหัวข้อ "แอปที่ดาวน์โหลดมา" → AI Drama Studio → เปิดสวิตช์ → อนุญาต (ถ้าติด ดูข้อ "ติดปัญหา" ด้านล่าง)
    • ไม่ให้ระบบประหยัดแบตปิดแอป และการแจ้งเตือน → กดอนุญาต
    • กด 🧪 ทดสอบระบบ → ขึ้น "✅ ระบบพร้อม" = ใช้งานได้

ติดปัญหา?

  1. เปิด Accessibility ไม่ได้ ขึ้นว่า "แอปถูกปฏิเสธไม่ให้เข้าถึง" หรือ "ควบคุมโดยการตั้งค่าที่จำกัด"เกิดกับแอปที่ไม่ได้ติดตั้งจาก Play Store (Android 13 ขึ้นไป) — กด "ปิด" → ในแอปกดปุ่ม "ข้อมูลแอป" (หรือ ตั้งค่า → แอป → AI Drama Studio) → กด ⋮ มุมขวาบน → "อนุญาตการตั้งค่าที่จำกัด" → ยืนยัน → กลับไปเปิดสวิตช์ Accessibility อีกครั้ง
  2. ยังขึ้น "แอปถูกบล็อกเพื่อปกป้องอุปกรณ์ของคุณ"แปลว่า Play Protect ยังเปิดอยู่ → ทำขั้นที่ 1 แล้วกดไฟล์ติดตั้งใหม่
  3. กดดาวน์โหลดแล้วค้าง / ไม่เสร็จเปิดหน้านี้ใน Chrome แล้วกดใหม่ หรือกดปุ่มดาวน์โหลดค้างไว้ → "ดาวน์โหลดลิงก์" · ถ้าเคยโหลดค้างมาก่อน ลบไฟล์ที่ค้างในหน้าดาวน์โหลดก่อน
  4. หลังอัปเดตเวอร์ชันใหม่ แอปไม่ทำงานมือถือบางรุ่นปิดสิทธิ์ Accessibility ให้เองหลังอัปเดต → เปิดแอป → 🔧 ตั้งค่าเครื่อง → เปิดสวิตช์ Accessibility ใหม่

อัปเดตเวอร์ชันใหม่: ดาวน์โหลดแล้วติดตั้งทับได้เลย (ปิด Play Protect ก่อนเหมือนเดิม) license และงานเดิมยังอยู่ครบ

💻 ใช้บนคอม (ไม่ต้องมีมือถือสำรอง)

ทดสอบแล้ว: Android Emulator (Android 14 + Play Store) บน Windows — ทำคลิปได้ครบ คลิป 10 วิ พูดภาษาไทยตรงบท ติดตั้งง่ายกว่ามือถือจริง (ไม่ต้องปิด Play Protect)

  1. ติดตั้งโปรแกรมจำลองมือถือที่มี Play Storeเช่น Android Studio (Device Manager → สร้างเครื่องแบบมี Play Store), BlueStacks หรือ LDPlayer · คอมควรมี RAM 8GB ขึ้นไป · ตัวที่ทดสอบแล้วคือ Android Studio ส่วนตัวอื่นยังไม่ได้ทดสอบ
  2. ตั้งภาษาเครื่องจำลองเป็นไทยSettings → System → Languages → Add a language → ไทย → ลากขึ้นไว้บนสุด (เครื่องจำลองตั้งมาเป็นภาษาอังกฤษ)
  3. ล็อกอิน Google (บัญชีสำรอง) → ติดตั้ง Meta AI จาก Play Store → ล็อกอินด้วย Facebook สำรอง
  4. ติดตั้งแอปเราเปิด Chrome ในเครื่องจำลอง → เข้าหน้านี้ → กดดาวน์โหลด → ติดตั้ง (หรือลากไฟล์ .apk ใส่หน้าต่างเครื่องจำลอง)
  5. เปิดแอปแล้วทำตาม "🔧 ตั้งค่าเครื่อง" เหมือนมือถือเปิดสิทธิ์ไฟล์ + Accessibility → กด 🧪 ทดสอบระบบ

⚠️ ใช้เครื่องจำลองครั้งละ 1 เครื่อง 1 บัญชี — การเปิดหลายเครื่องจำลองหลายบัญชีพร้อมกัน Meta อาจมองว่าเป็นฟาร์มบัญชีและระงับบัญชีได้
